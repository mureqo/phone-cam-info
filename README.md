# Phone Cam Info

Каталог сенсоров камер флагманских смартфонов 2018–2026.

Открой `index.html` в браузере — работает офлайн.

## Что внутри

- 53 телефона, сгруппированы по годам (и отдельно — телефоны разработчика).
- Для каждого: основная камера, ультраширик, телефото, перископ, фронтальная.
- Характеристики сенсоров: чип, Мп, диафрагма, размер сенсора, пиксель, ФВЦ, рид-нойз, ФР, мин. дистанция фокуса, динамический диапазон.
- Поиск по названию.
